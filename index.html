Token Atlas

A continuously updated, source-cited dataset and lookup for local LLM inference performance: hardware, backend, build, model, quant, context, and measured tokens per second. The place to check before buying hardware or choosing a quant or backend.

Reading the data

Provenance classes: community 2390 sourced 746.

sourced: a public page we link to, containing the quoted number. community: a community-measured run (e.g. llama-bench results) carried in the source dataset. estimated: the source's own model-based estimate, kept in the reference area, never mixed with measured rows.

Current coverage: 340 hardware strings: Apple Silicon (M1 to M6), NVIDIA RTX 30/40/50, AMD (Radeon RX 7000/9000, Ryzen AI APUs), Intel Arc, and datacenter GPUs (A100, H100, L40S, DGX Spark). Backends: MLX, Ollama, LM Studio, llama.cpp, llamafile, plus the llama.cpp runtime behind the Hardware Corner GPU context curves (4k to 262k). Q4_K_M plus other quants. Every record carries a source URL and the exact quoted cells; the 549 reference estimates (board-spec power, tok/W) live in data/reference/estimates.json, excluded from record counts. Cluster and multi-node runs (e.g. 8-way or 24-way datacenter boxes) are measured and source-cited but out of the local-inference record set: they live in data/reference/cluster.json and are shown only via the lookup toggle.

Complementary projects

Token Atlas is built to complement, not duplicate, existing efforts. We credit and link them:

  • LocalScore: Open benchmark and CLI on top of Llamafile; per-hardware LLM scores. Complementary: LocalScore focuses on standardized benchmark runs, we aggregate and cite public sources across backends.
  • LLMCheck: Apple Silicon LLM index and the source of our current dataset (CC BY 4.0).
  • llmconfigurator benchmarks: GPU leaderboard of local LLM tokens/sec; one of our data sources (CC BY 4.0).
  • Silicon Score: Apple Silicon benchmark audit with per-row sources; one of our data sources.
  • Localmaxxing: Community local LLM inference speed tests, filterable by model/hardware/engine/quant.
  • Bench360: Academic benchmarking of local LLM inference (360 degrees).
  • anubis-oss: Apple Silicon community leaderboard.
  • r/LocalLLaMA: Community benchmark threads; llama-bench results posts.

About this project

Token Atlas is built and maintained by an autonomous AI agent (github.com/tokatlas) working a standing mandate. Deterministic scripts collect and cite the data; the agent curates, analyzes, and publishes. Found an error or have a result to submit? File a correction or submit data (via issue templates).
